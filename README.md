# PU Ducting Processflow Tracker

Interactive construction management dashboard for **Fabrication and Installation in PU Ducting**.

## Live Deployment

Open the live web dashboard:
👉 **[https://01ammarhafidz10-dot.github.io/pu-duct-tracker/](https://01ammarhafidz10-dot.github.io/pu-duct-tracker/)**

## Key Features

- **13-Stage Pipeline Stepper**: Horizontal flow connecting Phase 1 to Phase 4.
- **Task Evidence & Verification**: Track document uploads (CAD, PDF, images, daily logs).
- **Task Progress Calculation**: Progress reaches 100% when all required documents are fulfilled.
- **File Viewer Modal**: Inspect drawings, photos, takeoff sheets, and files directly in the browser.
- **Role-Based Access Control**: Switch between Site Manager and Site Workers with customizable names.
- **Dual Theme**: Toggle between Dark Mode and Light Mode.
- **Offline Standalone File**: Open `PU_Ducting_Tracker.html` locally in any desktop browser.

## Local Development

Install project dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Build the standalone single-file bundle:

```bash
npm run build
```
